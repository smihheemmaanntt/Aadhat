============================================================
1. PRODUCT OVERVIEW
============================================================

Aadhat Software fruit aur sabji mandi ke vyapari, commission agent, trader, wholesaler aur stock based business ke liye bana accounting aur billing software hai.

Is software me customer account, item master, purchase, sale, standard sale, stock sale, receipt, payment, ledger, outstanding, crate manager, bill print, WhatsApp/SMS/mobile message, stock reports aur daily reports jaise kaam kiye ja sakte hain.

Common use:
- Customer ya party ka account banana
- Item / maal ka master banana
- Purchase ya stock entry karna
- Sale / bill banana
- Bill print karna
- Customer ko bill PDF WhatsApp, mobile SMS ya official WhatsApp API se bhejna
- Ledger / account statement dekhna
- Receipt aur payment entry karna
- Outstanding balance dekhna
- Stock balance aur stock reports dekhna
- Crate in/out aur crate ledger maintain karna
- Day book, cash book, sale register, purchase register dekhna

14. WHATSAPP / SMS / MOBILE MESSAGE
============================================================

14.1 Sending methods

Aadhat me different sending methods ho sakte hain:

Easy WhatsApp:
- Desktop WhatsApp based normal sending.
- User ke WhatsApp login/desktop setup par depend karta hai.

WhatsApp Official API:
- Approved Meta template ke through official sending.
- Template approved hona zaroori hai.
- PDF/document templates me PDF file attach hoti hai.

From Mobile:
- Connected Android mobile app/SIM ke through message/SMS send.
- Mobile online/connected hona chahiye.
- Correct SIM select hona chahiye.

Mobile App / Normal SMS:
- Android app se customer ko normal SMS bheja ja sakta hai.
- SMS me PDF bill/receipt/ledger link ja sakta hai.

14.2 From Mobile se message kaise jayega?

1. WhatsApp/SMS panel me Type = From Mobile select karein.
2. SIM dropdown me available SIM select karein.
3. Customer/mobile number select karein.
4. Message/PDF option choose karein.
5. Start Sending karein.

Support answer:
"From Mobile option me message connected Android phone/SIM se jayega. Type me From Mobile select kijiye, SIM choose kijiye aur Start Sending dabayiye."

14.3 SIM select kyu zaroori hai?

SIM select karne se software ko pata chalta hai ki message kaunse mobile SIM/subscriber se bhejna hai.

Support answer:
"Agar phone me 2 SIM hain to sending se pehle correct SIM select karna zaroori hai, warna message galat SIM se send ho sakta hai ya fail ho sakta hai."

14.4 Mobile message fail ho to kya check karein?

- Android mobile app online hai ya nahi
- Device internet connected hai ya nahi
- Selected SIM available hai ya nahi
- Mobile number valid hai ya nahi
- SMS permission mobile app me enabled hai ya nahi
- Plan/message limit expired to nahi

15. WHATSAPP OFFICIAL API
============================================================

15.1 Official API ka use

Official API ka use WhatsApp Business Cloud/API ke through template based messages bhejne ke liye hota hai.

Important:
- Template Meta par approved hona chahiye.
- Local template ka Local Type form ke hisab se hona chahiye, jaise Print Bill, Ledger, Receipt, Payment, Balance.
- Format English/Regional ke hisab se template select hota hai.
- Document/PDF bhejne ke liye header/document template required hota hai.

15.2 WhatsApp API Configuration

WhatsApp API Configuration screen me:
- Default sending setting
- WhatsApp Official API setting
- Template Editor
- Sync Templates
- Send Test Message
- Message Logs
- Default SIM / mobile message setting

Support answer:
"Official API setup ke liye WhatsApp API Configuration me Vendor ID aur Access Token enter karke Validate Official API karein. Validate successful hone ke baad templates sync/editor options use kar sakte hain."

15.3 Template Editor

Template Editor me local templates create/edit kiye ja sakte hain.

Fields:
- Template Code / Meta Name
- Title
- Language
- Category
- Header: none/text/document/image/video
- Sample Media
- Local Type
- Format: English / Regional
- Parameter Field
- Message Body
- Footer
- Quick Reply Buttons
- Template Parameters

Template banane ka general process:
1. Template Editor open karein.
2. New Template ya existing template select karein.
3. Local Type select karein, jaise Print Bill, Ledger, Receipt.
4. Format select karein: English ya Regional.
5. Header select karein:
   - Balance text-only ho to none/text use ho sakta hai.
   - Bill/Ledger/Receipt/Payment PDF ke liye document use karein.
6. Message body me dynamic variables add karein.
7. Parameter Field list se field select karke Add Variable karein.
8. Save Local karein.
9. Submit / Update Meta karein.
10. Approval ke baad template sending forms me show hoga.

Support answer:
"Official template banane ke liye Template Editor me Local Type aur Format select kijiye, message body me variables add kijiye, Save Local kijiye aur Submit/Update Meta karein. Approved hone ke baad wahi template Print Bill/Ledger/Receipt/Payment me select hoga."

15.4 Dynamic Parameters kya hote hain?

Dynamic parameters wo fields hain jo message bhejte waqt software automatically fill karta hai.

Examples:
- Firm Name
- Customer / Account Name
- Mobile No.
- City
- Bill Date
- Bill Total
- Receipt Date
- Payment Date
- Amount
- From Date
- To Date
- Opening Balance
- Closing Balance
- Balance Amount

Support answer:
"Template body me jo {{1}}, {{2}} jaise variables hote hain unme software form ke hisab se value fill karta hai, jaise customer name, bill date, firm name, total amount."

15.5 Template approved nahi aa raha ho to kya karein?

- Official API validate karein.
- Sync Templates click karein.
- Correct Local Type check karein.
- Correct language/format check karein.
- Template Meta par approved hai ya pending/rejected hai check karein.
- Same vendor/account ka token use ho raha hai ya nahi check karein.

Support answer:
"Agar template dropdown me nahi aa raha hai to pehle Official API validate kijiye, Sync Templates kariye, aur check kijiye ki template same Local Type aur English/Regional format me approved hai."

15.6 Balance text template me template name upar kyu dikhta hai?

Agar text header set hai to WhatsApp message ke top par header text dikhta hai. Agar customer ko header nahi chahiye to template me Header = none rakhein aur naya/updated template approval ke liye bhejein.

Support answer:
"Text message me upar template name dikh raha hai to wo template header hai. Template Editor me Header none karke template update/approval karna padega."

15.7 Official API message fail ho to common reason

- Template approved nahi hai
- Template name/language mismatch
- Parameter count mismatch
- Document template me PDF link missing
- Customer mobile number invalid
- Official API plan/account expired
- Token/vendor validation failed
- Meta quality hold ya template review issue

Support answer:
"Official API fail hone par template approval, language, parameters, PDF link aur mobile number check karein. Message Logs me actual response dekh sakte hain."

21. COMMON CUSTOMER QUESTIONS AND ANSWERS
============================================================

Q: Ledger kaise dekhu?
A: Ctrl + L se Ledger open kijiye, account select kijiye, From-To date select karke Show dabayein. Yahan se print/PDF/message bhi kar sakte hain agar option available ho.

Q: Bill kaise print karu?
A: Ctrl + P se Print Bills open kijiye, date range select karke Show dabayein, fir Print ya Print Hindi button use kijiye.

Q: Bill WhatsApp par kaise bheju?
A: Print Bills me Send WhatsApp/SMS par click kijiye, customer select kijiye, sending type choose kijiye, PDF Only ya PDF + Message select karke Start Sending dabayein.

Q: Hindi bill kaise bheju?
A: Print Bills me Regional select kijiye. Official API me Regional/Hindi approved template select karein, fir Start Sending karein.

Q: Official API template dropdown me nahi aa raha?
A: Official API validate karein, Sync Templates karein, aur check karein ki template same Local Type aur English/Regional format me approved hai.

Q: Receipt entry kaise karu?
A: F7 press karke Receipt open kijiye, account/mode/amount enter karke Save karein.

Q: Payment entry kaise karu?
A: F8 press karke Payment open kijiye, account/mode/amount enter karke Save karein.

Q: Outstanding balance kaha milega?
A: Ctrl + Y se Outstanding open karein. Date/filter select karke Show karein. Customer wise baki balance dikhega.

Q: Stock kaha se dekhu?
A: Stock Reports me Stock Balance ya Lot Wise Stock Report open karein. Date/filter select karke Show karein.

Q: Crate ka hisab kaha milega?
A: Crate Manager menu me Crate Ledger, Crate Outstanding, Crate In Register ya Crate Out Register open karein.

Q: Mobile se message kaise bheju?
A: WhatsApp/SMS panel me Type = From Mobile select karein, SIM select karein, customer tick karein aur Start Sending karein.

Q: From Mobile me SIM kyu select karna padta hai?
A: Agar phone me 2 SIM hain to correct SIM se message bhejne ke liye SIM select karna zaroori hai.

Q: Message send nahi ho raha?
A: Mobile/app online hai ya nahi, SIM selected hai ya nahi, number valid hai ya nahi, plan/message limit active hai ya nahi aur internet check karein.

Q: Official API message fail ho raha hai?
A: Approved template, language, parameters, PDF link aur mobile number check karein. Message Logs me exact status/response dekhein.

Q: Template kaise banau?
A: WhatsApp API Configuration me Template Editor open karein. Local Type, Format, Header, Body aur Parameters set karein. Save Local karke Submit/Update Meta karein.

Q: Template me variable kaise add karu?
A: Template Editor me Parameter Field list se field select karke Add Variable dabayein. Variable cursor position par message body me add hoga.

Q: Day wise sale kaha dekhu?
A: Reports me Day Wise Sale Report open karein, date select karein aur Show karein.

Q: Purchase register kaha milega?
A: Registers menu ya right panel se Purchase Register open karein, date range select karke Show karein.

Q: Cash book/day book kaha hai?
A: Right panel me Cash / Bank Book aur Day Book [Ctrl + D] options milte hain.

Q: Customer ka mobile number wrong hai to kya karein?
A: Account master me jaakar customer/account ka mobile number correct karein, fir message resend karein.

Q: Regional aur English me kya difference hai?
A: English format me message English body/template se jata hai. Regional me Hindi/local language template/body use hota hai.

Q: PDF Only aur PDF + Message me kya difference hai?
A: PDF Only me PDF/document link/file focus hota hai. PDF + Message me PDF ke saath text message bhi jata hai.

Q: Message Only ka use kab karein?
A: Jab sirf text notification bhejna ho aur PDF/document bhejna zaroori na ho.

22. SUPPORT STYLE GUIDELINES FOR AI AGENT
============================================================

AI agent ko answer dete waqt:
- Simple Hinglish me jawab de.
- Step-by-step bataaye.
- User ko exact menu/shortcut bataye.
- Agar form/version me option ka naam thoda different ho sakta hai to kahe: "Aapke version me naam thoda alag ho sakta hai."
- Password, token, database, code, internal file path, license bypass ya sensitive setting kabhi share na kare.
- Agar issue sending/API se related hai to pehle user se puchhe:
  - Kaunsa sending type use kar rahe hain?
  - Easy WhatsApp, Official API ya From Mobile?
  - Error message kya aa raha hai?
  - Template approved hai ya pending?
  - Mobile app online hai?
- Agar issue report/date ka hai to puchhe:
  - From date / To date kya selected hai?
  - Show button dabaya?
  - Account/item filter selected hai?

Good response examples:

Example 1:
"Ledger dekhne ke liye Ctrl + L press kijiye. Account select kijiye, From-To date set karke Show dabayiye. Agar print chahiye to Print button use karein."

Example 2:
"Bill WhatsApp par bhejne ke liye Ctrl + P se Print Bills open kijiye, date select karke Show karein, Send WhatsApp/SMS par click karein, customer tick karein aur Start Sending dabayein."

Example 3:
"Official API me template show nahi ho raha to pehle WhatsApp API Configuration me Validate Official API karein, fir Sync Templates karein. Template same Local Type aur English/Regional format me approved hona chahiye."

Example 4:
"From Mobile se message bhejne ke liye connected mobile app online rakhein, Type me From Mobile select karein, correct SIM choose karein aur Start Sending karein."

23. DO NOT ANSWER / SENSITIVE TOPICS
============================================================

AI support agent ko in topics par details nahi deni chahiye:
- Database ka location, structure, query ya password
- Source code changes
- Token, Vendor ID, API secret ka raw value
- License bypass ya activation bypass
- Admin password reset internal method
- Server credentials
- AnyDesk/remote credential
- Customer private data

Safe answer:
"Is type ki technical/sensitive setting ke liye please authorized support team se contact karein."
